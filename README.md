# 拼多多工作台02版

版本：**2.0.0**。独立源代码交付，仓库：[ManonDuu/-11262026-](https://github.com/ManonDuu/-11262026-)。不带旧仓库 Git 历史，不附带个人图片、原图、成品、草稿、历史、密钥或本机配置。默认仅监听本机 `http://127.0.0.1:5180/`，与旧版常用的 5173 端口隔离。

## 功能
- 自由生图、套图工作台、竞品参谋；统一手动浅色／深色，不随系统或时间自动切换。
- 竞品主图、详情页、选项图分别分析、预览、确认、生成；只处理选中类别。
- 主图按参考上传顺序循环对标；详情按完整卖点块映射，跨原图关联，不显示长条预览。
- 选项图默认一对一重构，可按套餐单独指定主商品、赠品、配件搭配。
- 成品独立分类，可编辑每张标题／文字、场景摘要和排版摘要，保存后按需重绘。

模型可能改错文字、产品外形或尺寸，出图后仍需人工核对。分析、生成、重绘可能由你配置的服务商计费，本软件不赠送额度，不承诺任何反代或模型永久可用。

## 安装
详见 **[中文详细安装说明](INSTALL.zh-CN.md)**（macOS / Windows、反代配置、数据迁移和报错排查）。

已安装 Node.js 后：
```sh
npm ci
npm run dev
```
浏览器打开 `http://127.0.0.1:5180/`。网页设置中填写本机可用的 API Base URL 和 Key；不要发送或提交到 Git。

自动化测试、类型检查和构建不能代替真实出图与目视验收。本轮自动化、一次真实应用反代请求及代表浏览器复验已完成，具体见 [验收范围与限制](docs/ACCEPTANCE.md)；这不是“所有功能无问题”的承诺。Windows 未在实机测试；此包只支持本地网页版，不提供桌面安装器／Tauri 构建。
